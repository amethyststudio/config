# Server Config Pack

This project provides ready-to-use Minecraft server config profiles with different goals.

The idea is simple:
- Want gameplay to feel Vanilla, but smoother? Use Vanilla+.
- Want more FPS/TPS headroom and can accept some behavior changes? Use PerformanceY.
- Want the highest performance possible? Use PerformanceX.

## Config Profiles

### 1) Vanilla+
**Goal:** Pure Vanilla behavior with the maximum performance available **without changing gameplay mechanics**.

- Keeps redstone behavior Vanilla-safe.
- Keeps mob AI and farm behavior Vanilla-safe.
- Avoids gameplay-altering throttles.
- Best choice for survival communities, SMPs, and technical players who want normal Minecraft behavior.

Path: [Minecraft/Vanilla+](Minecraft/Vanilla+)

Status: **Available now**

### 2) PerformanceY
**Goal:** Better performance than Vanilla+ with **small gameplay trade-offs**.

- Designed for servers that need extra headroom.
- Some Vanilla behavior may be modified.
- Good middle ground between authenticity and performance.

Path: [Minecraft/PerformanceY](Minecraft/PerformanceY)

Status: **Coming soon**

### 3) PerformanceX
**Goal:** Maximum performance from configs, with gameplay compromises accepted.

- Aggressive optimization profile.
- May significantly change Vanilla behavior.
- Recommended only if performance is the top priority.

Path: [Minecraft/PerformanceX](Minecraft/PerformanceX)

Status: **Coming soon**

## Which One Should I Pick?

- If you are not sure: choose **Vanilla+**.
- If your server struggles during peak player count: wait for **PerformanceY**.
- If you run very large servers and accept gameplay changes: wait for **PerformanceX**.

## Quick Start (Non-Technical)

1. Open the folder of the profile you want.
2. Copy its config files into your server folder.
3. Start the server once.
4. Join and test your world.

If you are a casual server owner or just playing with friends, **Vanilla+ is the safest option**.
